# 🔑 .env Keys Explained

**All the keys you need and where to get them**

---

## Required Keys (Must Have)

### 1. OPENAI_API_KEY
**What it's for:** AI agents use this to generate content (research, ad copy, images)

**How to get it:**
1. Go to https://platform.openai.com/
2. Sign in or create account
3. Click "API Keys" in left sidebar
4. Click "Create new secret key"
5. Give it a name (e.g., "MetaMarkAgency")
6. Copy the key (starts with `sk-proj-...`)
7. Paste in .env: `OPENAI_API_KEY=sk-proj-your-key-here`

**Cost:** ~$0.01-0.06 per agent execution  
**Budget:** Set aside $5-20/month for testing

---

### 2. FIREBASE_PROJECT_ID
**What it's for:** Tells the system which Firebase project to use (staging environment)

**How to get it:**
1. Complete Firebase setup (see FIREBASE_SETUP_GUIDE.md)
2. Go to https://console.firebase.google.com/
3. Click on your project
4. Click ⚙️ gear → "Project settings"
5. Copy "Project ID" (e.g., `metamark-agency-staging`)
6. Paste in .env: `FIREBASE_PROJECT_ID=metamark-agency-staging`

**Cost:** FREE (Firebase free tier)

---

### 3. FIREBASE_CREDENTIALS_PATH
**What it's for:** Points to your Firebase credentials JSON file

**How to get it:**
1. Complete Step 3 of Firebase setup guide
2. Download the JSON file from Firebase Console
3. Rename to `firebase-staging-key.json`
4. Put in project root folder
5. Set in .env: `FIREBASE_CREDENTIALS_PATH=./firebase-staging-key.json`

**Important:** Never commit this file to git!

---

## Optional Keys (For Full Features)

### 4. FACEBOOK_APP_ID
**What it's for:** Identifies your Facebook app (needed to post ads)

**How to get it:**
1. Go to https://developers.facebook.com/
2. Log in with Facebook account
3. Click "My Apps" → "Create App"
4. Choose "Business" type
5. Fill in app name (e.g., "MetaMarkAgency")
6. Copy "App ID"
7. Paste in .env: `FACEBOOK_APP_ID=your-app-id`

**Cost:** FREE

---

### 5. FACEBOOK_APP_SECRET
**What it's for:** Secret key for Facebook app authentication

**How to get it:**
1. Same app as above
2. Go to "Settings" → "Basic"
3. Click "Show" next to "App Secret"
4. Copy the secret
5. Paste in .env: `FACEBOOK_APP_SECRET=your-app-secret`

**Important:** Keep this secret! Never share or commit to git.

---

### 6. FACEBOOK_ACCESS_TOKEN
**What it's for:** Allows posting to your Facebook page/ads

**How to get it:**
1. In your Facebook app dashboard
2. Go to "Tools" → "Graph API Explorer"
3. Select your app
4. Click "Generate Access Token"
5. Grant permissions: `pages_manage_posts`, `ads_management`
6. Copy the token
7. Paste in .env: `FACEBOOK_ACCESS_TOKEN=your-access-token`

**Note:** Tokens expire! You may need to regenerate.

---

### 7. FACEBOOK_AD_ACCOUNT_ID
**What it's for:** Specifies which ad account to post ads to

**How to get it:**
1. Go to https://business.facebook.com/
2. Click "Business Settings"
3. Go to "Ad Accounts"
4. Copy your ad account ID (starts with `act_`)
5. Paste in .env: `FACEBOOK_AD_ACCOUNT_ID=act_your-account-id`

**Note:** You need an active Facebook Ads account.

---

### 8. FACEBOOK_PAGE_ID
**What it's for:** Specifies which Facebook page to post to

**How to get it:**
1. Go to your Facebook page
2. Click "About"
3. Scroll to "Page ID"
4. Copy the number
5. Paste in .env: `FACEBOOK_PAGE_ID=your-page-id`

**Alternative:**
- Use Graph API Explorer
- Query: `/me/accounts`
- Copy the `id` for your page

---

## Environment Configuration

### 9. ENVIRONMENT
**What it's for:** Tells the system which environment you're in

**Options:**
- `development` - Local JSON files, no Firebase, no Facebook needed
- `staging` - Firebase staging, safe testing with real APIs
- `production` - Protected, agents can't write directly (future)

**Recommended:** `staging` for testing with Firebase

**Set in .env:** `ENVIRONMENT=staging`

---

## Optional Test Mode

### 10. TEST_MODE
**What it's for:** Run without Facebook API (for testing locally)

**How to use:**
1. Uncomment in .env: `TEST_MODE=true`
2. System will simulate Facebook posts without actually posting
3. Good for testing agent logic without spending on ads

**When to use:**
- Testing new features
- Don't have Facebook credentials yet
- Want to test without posting real ads

---

## Optional Rate Limiting

### 11. OPENAI_RATE_LIMIT
**What it's for:** Override default OpenAI rate limit (default: 50 requests/minute)

**When to change:**
- You have a higher tier OpenAI account
- You're hitting rate limits

**Set in .env:** `OPENAI_RATE_LIMIT=100`

---

### 12. FACEBOOK_RATE_LIMIT
**What it's for:** Override default Facebook rate limit (default: 200 requests/minute)

**When to change:**
- You have a higher tier Facebook account
- You're hitting rate limits

**Set in .env:** `FACEBOOK_RATE_LIMIT=500`

---

### 13. BUDGET_ALERT_THRESHOLD
**What it's for:** Set when you get budget alerts (default: 75%)

**Options:**
- `75` - Alert at 75% budget used (recommended)
- `50` - Alert at 50% (conservative)
- `90` - Alert at 90% (aggressive)

**Set in .env:** `BUDGET_ALERT_THRESHOLD=75`

## Quick Start Configurations

### Minimal (Development Only)
```bash
OPENAI_API_KEY=sk-proj-your-key-here
ENVIRONMENT=development
TEST_MODE=true
```

### Recommended (Staging with Firebase)
```bash
OPENAI_API_KEY=sk-proj-your-key-here
ENVIRONMENT=staging
FIREBASE_PROJECT_ID=metamark-agency-staging
FIREBASE_CREDENTIALS_PATH=./firebase-staging-key.json
```

### Full (All Features)
```bash
# OpenAI
OPENAI_API_KEY=sk-proj-your-key-here

# Facebook
FACEBOOK_APP_ID=your-app-id
FACEBOOK_APP_SECRET=your-app-secret
FACEBOOK_ACCESS_TOKEN=your-access-token
FACEBOOK_AD_ACCOUNT_ID=act_your-account-id
FACEBOOK_PAGE_ID=your-page-id

# Firebase Staging
ENVIRONMENT=staging
FIREBASE_PROJECT_ID=metamark-agency-staging
FIREBASE_CREDENTIALS_PATH=./firebase-staging-key.json
```

## Security Checklist

- [ ] `.env` is in `.gitignore` (never commit secrets!)
- [ ] `firebase-staging-key.json` is in `.gitignore`
- [ ] OpenAI API key starts with `sk-proj-` or `sk-`
- [ ] Facebook app secret is kept private
- [ ] Firebase credentials JSON is in project root
- [ ] No secrets are hardcoded in Python files

## Testing Your Configuration

**Run this to verify all keys are set:**

```bash
python3 -c "
import os
from dotenv import load_dotenv

load_dotenv()

print('Checking .env configuration...\n')

# Required
print('✅ OPENAI_API_KEY:', '✓ Set' if os.getenv('OPENAI_API_KEY') else '✗ Missing')
print('✅ ENVIRONMENT:', os.getenv('ENVIRONMENT', 'development'))

# Firebase (if staging)
if os.getenv('ENVIRONMENT') == 'staging':
    print('✅ FIREBASE_PROJECT_ID:', '✓ Set' if os.getenv('FIREBASE_PROJECT_ID') else '✗ Missing')
    print('✅ FIREBASE_CREDENTIALS_PATH:', '✓ Set' if os.getenv('FIREBASE_CREDENTIALS_PATH') else '✗ Missing')

# Facebook (optional)
fb_keys = ['FACEBOOK_APP_ID', 'FACEBOOK_APP_SECRET', 'FACEBOOK_ACCESS_TOKEN', 
           'FACEBOOK_AD_ACCOUNT_ID', 'FACEBOOK_PAGE_ID']
fb_set = sum(1 for k in fb_keys if os.getenv(k))
print(f'\n📘 Facebook API: {fb_set}/{len(fb_keys)} keys set')

print('\n✅ Configuration looks good!' if os.getenv('OPENAI_API_KEY') else '\n⚠️ Missing required keys!')
"
```
